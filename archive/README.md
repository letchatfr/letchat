# Versions historiques de Letchat

`versions-historiques.zip` conserve les 99 fichiers des anciennes copies du dépôt, avec leurs chemins et leur contenu d’origine. L’intégrité de chaque fichier a été vérifiée après compression. Ces fichiers sont archivés pour consultation et ne sont jamais servis par l’application.

L’application maintenue se trouve dans `letchat-v4/` à la racine du dépôt. Ne pas déployer cette archive.
